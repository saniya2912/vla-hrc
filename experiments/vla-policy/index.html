Overview

Zero-shot baseline and fine-tuning strategy

As a baseline, the pretrained π0.5 policy was first deployed directly in the Baxter MuJoCo environment without fine-tuning. Because π0.5 was developed for a 7-DOF Franka robot, its action and state interfaces did not directly match Baxter's 15-DOF system, so a kinematic mapping was introduced to connect the policy's outputs to Baxter's joint-space controller and gripper actuator. This zero-shot evaluation established the baseline performance before introducing Baxter-specific demonstrations and LoRA fine-tuning — the foundation every later stage of this project builds on.

System & methodology

Platform, simulation, and adaptation strategy

Robot DE NIRO, a human-centred, dual-arm mobile research platform built around a Baxter upper body, is this project's long-term deployment target. Baxter was chosen so the simulation and physical-deployment platforms match — same 7-DOF right-arm kinematics, same Rethink parallel-jaw gripper — so a fine-tuned policy and inference stack transfer to the physical robot. The Baxter arms are also equipped with wrist-mounted cameras, providing the visual observations used for demonstration collection and policy execution. Development was performed primarily in MuJoCo to enable rapid experimentation, safe debugging, and automated demonstration collection, and to allow train–inference mismatches to be identified and resolved before physical deployment.

Experimental setup

Task design & demonstration collection

The task focuses on rearranging three coloured blocks (red, green, blue) between near-side and far-side regions of a tabletop. To simplify the manipulation problem, the task is decomposed into six reusable primitives — moving each block to either the near or far side — which the VLM planner later composes into the full 2³ = 8 goal configurations. Demonstrations were generated autonomously in MuJoCo using damped least-squares inverse kinematics and a fixed seven-stage pick-and-place sequence (pre-grasp → descend → grasp → lift → transport → place → return), with block positions randomised within ±3 cm (x) / ±2 cm (y). A total of 600 demonstrations were collected, 100 per primitive task, then converted to the LeRobot dataset format with normalisation statistics computed from the project's own training data (1st/99th-percentile quantile bounds) rather than the statistics bundled with pretrained π0.5.

Results

Baseline policy performance

The zero-shot π0.5 baseline achieved 15.0% overall trial-level success (9/60 trials) — a non-trivial result for a model never trained on Baxter, but one concentrated almost entirely on the red block. Failure cases

Where the base policy struggles

Zero-shot performance was concentrated on the red block (70% success on the red-far task, 80% block-lifted rate) and collapsed on blue and green (0/10 on every blue and green task). The pretrained model cannot reliably distinguish between the three block colours from the Baxter camera viewpoint, defaulting to the dominant pretraining behaviour of approaching whatever object sits near the centre of the scene — which happens to be the red block's position.
